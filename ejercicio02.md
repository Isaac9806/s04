# Visual Studio Code

## Descripción
Visual Studio Code es un editor de código fuente ligero pero muy potente, desarrollado por Microsoft. Está disponible para Windows, macOS y Linux.

### Características principales
- Soporte nativo para múltiples lenguajes de programación.
- Terminal integrada de fácil acceso.
- Ecosistema gigante de extensiones y temas.
